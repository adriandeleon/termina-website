- **Six interface languages**: English, Italian, Spanish, French, Portuguese and German, chosen under Settings → Appearance → Language.
- **Automatic follows the system**, and uses English when the system's language is not one of the six.
- **Each listed in its own name**, so someone who has landed in a language they cannot read can still find theirs.
- **English is the fallback.** A string missing from a translation shows in English rather than as a gap, and a test holds the six catalogues to the same set of strings.
- **The menus, the palette, the Settings window and the dialogs** are translated. A change takes effect after a restart.

See [Appearance](/docs/appearance#language).
